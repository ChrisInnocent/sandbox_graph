# Proposal

## Why

现有 E1/E2/C1/C2/C3 已有调度、账本和复检接口，但缺少 CubeSandbox、Kuasar、AgentENV 的实际部署探测、安装修复及参数适配，无法仅凭环境声明准备真实测试环境。将这些确定性操作落实为源码可追溯的执行代码，补齐已有环境复用和检查失败后的修复闭环，避免把通用 handler 测试通过误认为产品安装能力交付。

## What Changes

- 实现版本化环境声明、逐节点/角色属性检查、部署发现、已有证据复用及必要事实补全；区分目标、文件值、运行时生效值和真实资源占用。
- 为三产品实现显式部署 profile、真实命令/协议探测、配置解析和修复动作目录；支持一组单节点或多节点，允许角色共置，不按机器数量猜角色。
- 基于已审计源码固化安装制品、依赖顺序、配置键、默认/无限制语义、重载方式和后置断言。分别交付实际适配代码及测试，注册目录不能替代实现。
- 将连接、认证、属性不满足、未安装、服务异常、配置漂移、注册失败及观测权限不足映射到明确修复或阻塞原因。既有授权范围内自动修复；未知状态先对账，无法修改的硬件条件如实阻塞。
- 实现凭据引用、公钥幂等配置与新连接验证，固定摘要的安装制品、逐步持久执行、文件变更前置检查、必要重启、失败恢复和共享宿主资源互斥。
- 按三产品真实源码配置/复用沙箱服务端 API 凭据并接入测试客户端，独立验证缺失/错误凭据被拒与正确凭据可用；区分主机 SSH、控制 API、租户根密钥及逐沙箱数据面 token，不预设统一 `x-api-token`。记录鉴权模式对比较和限流的影响，重入不反复生成或覆盖已有秘密。
- 将选型测试的“放宽平台限制”翻译为各产品可验证的参数；不混淆单沙箱规格、平台配额和缓存/预热/内存回收策略。
- 实现独立复检、准备资源清理、逐节点完整报告及初始资源 inventory；将环境检查结果与测试阶段 preflight 证据连接起来。
- 补齐初始 SSH 的标准库 helper bootstrap 与离线资产投递，绑定机器、制品摘要及入口 CAS；通过有限重入、宿主锁和独立自检准备后续环境图执行端，不把初始化回执当作产品就绪验收。
- 提供明确的检查/计划/执行/对账/报告 CLI 和 E1—C3 接线，使环境准备不依赖先声明未验证的测试能力为 supported；修复 check-only 汇总和配置恢复的现有接线缺口。
- 增加三产品配置语义黄金测试、真实执行器的受控协议测试、Linux/SSH/systemd 集成测试及逐产品真实部署验收。分别记录实现、受控验证和真实部署状态。

## Capabilities

### New Capabilities

- `sandbox-environment-adapters`：三产品部署 profile 的真实探测、属性检查、差异修复、安装调参、证据交付与可恢复执行合同。

### Modified Capabilities

无已归档主 spec。当前 `openspec list --specs` 为空。本能力具体化在途 `sandbox-evaluation-workflow` 的 `environment-readiness` ENV-01—24，不复制或替换该通用能力；设计列出与原 change 的接线、路由和任务边界，实施时同步原文档。

## Impact

- 新增 `sandbox_graph/environment/`、`scripts/environment/` 和 `tests/environment/`；修改现有环境 handler、运行服务/选择器、图装配、命令入口及必要的远端执行协议。复用 PostgreSQL、ArtifactStore、OperationService 和租约机制。
- 上游仓库作为只读源码依据，版本取自 `docs/source-audit/upstream-sources.json`；不修改其产品代码，不把上游浮动 main/latest 安装命令直接作为实验制品。
- 计划交付覆盖三产品各至少一个可安装的单机 profile 和多节点角色组合；具体 profile、已有其他部署的发现/阻塞边界见 design。不能仅完成某一产品后将本 change 标为完成。
- 真实访问、制品来源/摘要和目标部署参数作为运行输入；缺少它们不阻塞适配代码与受控验证，仅阻塞相应真实执行。主机内核替换、重启、数据迁移和新增资源等影响超出已有授权的动作保留精确 gate。
- 新代码需要保留旧 graph/handler 版本恢复能力。环境文件与节点结果使用新 schema，不静默把旧摘要升级为具备完整在位证明的环境报告。
- 本 change 已进入 apply：通用底层合同、SSH/访问与主机探测、凭据/鉴权、配置事务、修复计划、有限参数、远端 journal、OperationService gateway 和注册式动作等已实现一部分，进度以 tasks.md 勾选为准。三产品产品适配、环境图/CLI 接线及真实部署验收仍未完成；已实现公共底层不等于三种沙箱环境准备能力可用。
